# Data Dictionary

## Overview

The data dictionary for this project has been prepared as part of the Excel workbook used during the data preparation phase.

It provides a detailed description of all dataset attributes, including:

- Column names
- Excel data types
- PostgreSQL data types
- Attribute descriptions

The data dictionary serves as a reference for understanding the dataset and supports the SQL analysis, Power BI dashboard, and project documentation.

## Location

The complete data dictionary is available in:

```text
Excel/
└── IBM_HR_Analytics_Cleaned.xlsx
    └── Data Dictionary
```

## Summary

The IBM HR Analytics dataset contains **35 columns** describing employee demographics, job characteristics, compensation, performance metrics, satisfaction scores, and employment history.

The documented data dictionary ensures consistent interpretation of the dataset throughout the project and provides a centralized reference for all project artifacts.
